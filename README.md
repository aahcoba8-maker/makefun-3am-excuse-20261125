# The 3 AM Excuse — make.fun entry

One line, under 200 characters, in the voice of a hardware wallet refusing to sign a transaction at 3 AM:

> I don't sign at 3 AM — that's when your seed phrase dreams, and I never wake it for a trade you'll regret by breakfast.

`main.py` writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to the script directory), with a self-gate assert matching the
kit's 1–200 character, non-whitespace, single-line rule.
